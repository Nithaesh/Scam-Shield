# 🛡️ Scam Shield v2 (Production Upgrade)

Scam Shield v2 is an enterprise-ready, citizen-first anti-scam intelligence platform tailored for Indian users. It wraps the proven 5-agent multi-agent reasoning core in a modern, production-grade **FastAPI** backend with real-time **Server-Sent Events (SSE)**, paired with a high-performance **Next.js 14/15 App Router** bilingual frontend.

---

## Key Highlights
- **100% Non-Destructive**: Built entirely inside `v2/` without touching legacy files.
- **Dual LLM Architecture**: Primary Gemini Flash with automated Groq fallback.
- **Sub-Second Streaming**: Live SSE agent cards (Extractor, Pattern Analyst, Entity Checker, Judge, Advisor).
- **Citizen Safety & Accessibility**:
  - Elderly-friendly interface (18px+ base font, 48px+ touch targets).
  - Bilingual (English & Hindi) with Web Speech API audio read-aloud.
  - WhatsApp family warning generation (max 280 characters).
  - 100% privacy preserving (no message persistence, zero tracking).
